## 二、简介（可直接复制）

```
ExeTrace 是一个 Windows 小工具：后台记录你打开过的每一个应用，随时一键找回、钉回桌面。

AI 让每个人都能快速做出自己的小软件，但很多作者没有编程背景——不做桌面快捷方式，也不引导你创建。结果是：用完关掉界面，就再也找不到它装在哪了。ExeTrace 就是为这件事做的：关窗后它缩进托盘继续记录，想找的时候按 Ctrl+Alt+E 随时呼出。

■ 主要功能
· 实时记录 + 历史回填：后台定期扫描，凭"出现可见窗口 / 由资源管理器启动"确认真实打开，后台服务与更新器不会被误记
· 一秒定位：搜索、按最近/次数/名称排序；双击直接启动
· 一键钉回桌面：选中 → 创建桌面快捷方式（自带起始位置与图标，同名自动编号，绝不覆盖已有文件）
· 钉任意程序：不在历史里的软件，直接选 exe 或软件文件夹也能钉
· 常驻托盘：关窗继续记录；开机自启是可选开关（默认关闭）

■ 体积与内存（Win32 原生版实测）
· 单文件 exe 1.61 MB，双击即用、无需安装
· 托盘常驻约 2 MB；窗口打开约 58 MB

■ 开源免费
GitHub：https://github.com/joker1point/ExeTrace
仓库里有功能演示（6 张真机操作动图），以及 Python / Rust 两个实现

■ 音乐
BGM：鹭起Herons -《云梦泽》
来源：网络音乐，版权归原作者所有；若作者或平台有异议，我会立即更换或删除

#ExeTrace #Windows #效率工具 #开源 #软件推荐 #AI
```
