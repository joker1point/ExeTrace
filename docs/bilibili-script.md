## 五、录屏拍摄指令

### 演示前的准备

1. **隐私处理（必做）**：真实历史列表含 300+ 应用（本地路径、内部工具名）。两种做法二选一：
   - **推荐**：用独立数据目录起一个"演示专用"实例——启动前设置环境变量 `EXETRACE_DATA_DIR=<临时目录>`，它会从注册表回填一份通用列表，不暴露私人使用记录
   - 或者：后期对路径列打码
2. **准备一个"难找"的主角软件**：挑一个没有被钉到桌面的绿色工具（比如 7-Zip、一个单文件小工具），让"找不到 → 找到"的反差成立
3. **录制前先把列表滚到中间位置**，演示①时搜索能体现出"过滤"的动效

### 三段演示的镜头要点

| 演示 | 关键镜头 | 别忘 |
|---|---|---|
| ① 钉桌面 | 从搜索 → 双击启动 → 一键创建 → 桌面收到快捷方式，**首尾闭环** | 桌面快捷方式生成的瞬间要有 0.5 秒定格 |
| ② 实时记录 | 打开软件后**不要等**，立刻切回 ExeTrace（体现"立刻出现"） | 底部"刚刚打开"提示条要拍进去 |
| ③ 历史+搜索 | 搜索框输入时给键盘特写；右键菜单要拍清楚 | 拍一下"文件已丢失"灰显效果更好（体现细节） |
